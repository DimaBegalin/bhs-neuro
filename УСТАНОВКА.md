# Установка на новый MacBook

Пятнадцать минут, программистом быть не нужно.

## Шаг 1. Python

Скачайте Python 3.12 с официального сайта и установите как обычную программу:
https://www.python.org/downloads/release/python-31210/
(внизу страницы файл «macOS 64-bit universal2 installer»).

## Шаг 2. Папка

Распакуйте архив и положите папку «нейропрофориентация» в Документы.

## Шаг 3. Установка окружения

Откройте папку, нажмите на файл `setup.command` ПРАВОЙ кнопкой и выберите
«Открыть», затем подтвердите. Окно само поставит всё нужное и напишет
«ГОТОВО». Делается один раз.

## Шаг 4. Ободок

1. Включите ободок кнопкой.
2. Откройте приложение Mind Tracker BCI и подключите ободок в нём.
3. Оставьте Mind Tracker открытым на вкладке «Мониторинг»: он ведёт поток
   данных, наша система читает его параллельно.

## Шаг 5. Запуск

Нажмите на `START.command` правой кнопкой и выберите «Открыть».
Когда macOS спросит про Bluetooth, разрешите. Через несколько секунд
откроется страница теста.

- Тест: http://127.0.0.1:8080/index.html
- Панель специалиста: http://127.0.0.1:8080/panel.html, код 2026
- Облачная панель (с любого устройства):
  https://bhs-neuro-panel-edygovich.vercel.app, код 2026

Остановить систему: закрыть окно терминала со СТАРТом.

## Если что-то не так

- Страница теста пишет «Запись не запустилась»: проверьте, что ободок
  включён и Mind Tracker подключён к нему на «Мониторинге».
- Прибор не находится: выключите и включите ободок, при первом знакомстве
  с этим компьютером подключите его в Mind Tracker заново.
- Тест прошёл, а отчёта нет: откройте панель, карточка появляется через
  полминуты после финального экрана.
