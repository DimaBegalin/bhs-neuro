# Офлайн: сырая ЭЭГ не покидает ноутбук

Сессия, расчёт и отчёты работают без интернета. Первый вход менеджера требует сеть, дальше вход действует 30 дней офлайн. Визиты уходят в Supabase фоновой очередью. В облако попадают только карточка ученика, ответы, итоги и агрегаты нейромониторинга. Сырая ЭЭГ и пульс остаются на ноутбуке. Причины две: нейроданные подростков — чувствительные данные, а связь в школах ненадёжна.
