# Установщик без подписи кода, обновления вручную

Сертификат подписи не покупаем, автообновление не делаем: так решил заказчик. Цена этого решения: при каждой установке SmartScreen показывает «Windows защитила ваш компьютер». Чтобы менеджеры не терялись, приложение показывает плашку «Доступна версия 2.x — скачать», а к установщику прилагается инструкция со скриншотами. Решение пересматриваем, если менеджеров станет много или антивирусы начнут блокировать установку.
