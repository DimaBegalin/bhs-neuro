# Профиль относительно самого ученика, сходство по корреляции

Локальных норм нет, а американские нормы O*NET к казахстанским подросткам неприменимы. Поэтому до ~300 учеников профиль интересов читается относительно самого ученика. Сходство с профессией — корреляция Пирсона между шестью баллами ученика и профилем профессии из O*NET (CC BY 4.0). Корреляция сравнивает форму профиля и не зависит от того, щедро ли ученик ставит оценки. Плоский профиль честно называется «пока не выражены». Сложные индексы конгруэнтности (Iachan, C-index) простую корреляцию не превосходят. Нормы по полу не вводим, чтобы не закреплять стереотипы.
