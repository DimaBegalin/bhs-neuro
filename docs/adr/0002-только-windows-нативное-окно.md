# Только Windows, нативное окно без локального веб-сервера

Версия 2.0 — одна программа для Windows 10/11: Python и pywebview (WebView2), установщик Inno Setup, официальный SDK ободка. Интерфейс говорит с ядром через мост pywebview (JS ↔ Python), а не через HTTP на 127.0.0.1:8765. Тест больше не открывается в браузере и не живёт на Vercel. macOS-мост держался на обходных путях: второе подключение к Mind Tracker, OCR экрана, права LaunchAgent. Поэтому macOS заморожен в версии 1. На Mac приложение запускается только для разработки, с проигрывателем записанных сессий вместо прибора.

## Considered Options

- Electron: тяжелее (~150 МБ), а ядро и так на Python.
- Нативный Qt/WPF: интерфейс пришлось бы переписать целиком.
- Оставить локальный сервер и браузер: это и было источником «перекидывания на сайт», CORS/PNA и зависимости от Chrome.
