# Рекомендация строится без ЭЭГ

Продукт с ободком, но рекомендация по кластерам считается только по опроснику интересов и задачам. Нейромониторинг показывается в отчёте отдельно, с пометкой «экспериментальный показатель». Мы не нашли ни одного рецензируемого исследования, где потребительская ЭЭГ (1–4 сухих канала) предсказывала бы профессию подростка. Интересы RIASEC и пространственные способности, наоборот, подтверждены мета-анализами и лонгитюдами. Поэтому сессия без ободка даёт ту же рекомендацию, а ЭЭГ-метрики возвращаются в расчёт только после собственной валидации: повторный замер и добавочная валидность сверх опросника.

## Consequences

- Старые индексы (focus, stress, flow, «цена» решения, fit, архетипы) и метрики Mind Tracker удалены, а не перенесены.
- Слова «мозг показал», «диагностика», «предрасположенность», «стресс» запрещены в шаблонах отчёта. Это проверяет автотест.
