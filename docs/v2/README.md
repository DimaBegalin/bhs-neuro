# Версия 2.0 — «Профориентация BHS с нейромониторингом»

Методика, расчёт, отчёты, архитектура и план описаны в документе
[«Профориентация BHS 2.0 — методология и продукт»](https://claude.ai/code/artifact/cdb9b008-e672-462d-86b7-fd15ad4923b8).
Словарь терминов — [CONTEXT.md](../../CONTEXT.md), решения — [docs/adr](../adr).

Код версии 2.0 живёт в пакете `app/`. Пакеты `bridge/`, `analyzer/` и `report/` — это
версия 1: из них переносится только то, что названо в документе. Остальное удаляется,
когда версия 2.0 заменит версию 1 у менеджеров.

## Этап 0: проверка ободка через SDK на Windows

Цель — убедиться до начала разработки, что официальный SDK на Windows держит ободок
без Mind Tracker и отдаёт сигнал в тех же единицах, что записи на Mac.

1. Скачать артефакт `BHS-SDK-Check-Windows-x64` из прогона workflow «Windows EXE» на ветке `v2`.
2. На Windows-ноутбуке закрыть Mind Tracker, надеть ободок и нажать на нём кнопку.
3. Запустить `BHS-SDK-Check.exe`. Если SmartScreen предупредит, нажать «Подробнее», затем «Выполнить в любом случае».
4. Следовать подсказкам: около 30 с с закрытыми глазами, затем около 30 с с открытыми.
5. Прислать разработке папку `BHS-проверка-ободка_…` с рабочего стола целиком.

Ворота этапа пройдены, когда во всех пяти пунктах стоит «ОК». Если не прошла только
реакция альфы, проверку повторяют, держа глаза закрытыми весь отрезок. У четверти
записей на Mac эта реакция тоже была слабой.

Пробный прогон без прибора на Mac:
`.venv/bin/python tools/sdk_check.py --fake --phase 8 --no-wait`.

## Этап 1: каркас приложения

Запуск на Mac (вместо ободка — проигрыватель последней записанной сессии):

```
.venv/bin/python -m app.main                 # проигрыватель, реальное время
.venv/bin/python -m app.main --device sim --fast   # имитатор, фон по 3 с
.venv/bin/python -m app.main --replay путь.npz --speed 2
```

Данные разработки пишутся в `var/` (в git не попадает), на Windows — в
`%LOCALAPPDATA%\BHS Profor`. Сквозной прогон окна со снимками экранов:
`.venv/bin/python tools/v2/e2e_window.py ПАПКА`.

Что уже есть: заведение ученика, подключение ободка с качеством по каналам,
согласие ученика (ru/kk), модуль фона, итог менеджера, список сессий. Сессия
переживает сбой программы: при следующем запуске она собирается и получает
статус «оборвалась при сбое». Опросник, карточки и задачи — этап 2.

## MVP: запуск на Windows

1. Скачать артефакт `BHS-Profor-Windows-x64` из последнего прогона workflow «Windows EXE» на ветке `v2`.
2. Положить `BHS-Profor.exe` на ноутбук. Mind Tracker должен быть закрыт.
3. Запустить. SmartScreen: «Подробнее» → «Выполнить в любом случае».
4. «Новый ученик» → класс, язык, режим. С ободком: надеть, нажать кнопку на ободке, «Подключить».
5. После батареи на экране менеджера будут интересы, три кластера с профессиями, задачи на вращение, стиль работы и предупреждения о достоверности.

Сессии лежат в `%LOCALAPPDATA%\BHS Profor\sessions\<id>\`: `meta.json`, `events.json`, `signal.npz`, `result.json`.
В облако MVP ничего не отправляет: синхронизация — этап 4. Оформленные саммари и PDF для родителя — этап 3.

Методики MVP и их лицензии — [ADR 0006](../adr/0006-методики-mvp-и-лицензии.md). Пилот бесплатный:
пункты интересов IIP разрешены только для некоммерческого использования.
