# Пилот версии 2.0

**Цель.** Проверить на живых учениках то, что нельзя проверить на Mac и в CI: хронометраж, стабильность ободка между учениками, надёжность шкал на русском и казахском, понятность саммари.

## Состав

- 1–2 ноутбука менеджеров с установленной версией 2.0. Остальные менеджеры пока работают на версии 1.
- 30–50 учеников 8–11 классов, по возможности поровну на русском и казахском.
- Пилот бесплатный для участников: пункты интересов IIP разрешены только некоммерчески (ADR 0006).

## До старта

- [ ] Этап 0: `BHS-SDK-Check.exe` на каждом пилотном ноутбуке — все пять пунктов «ОК».
- [ ] Казахские тексты вычитаны носителем (опросники, карточки, интерфейс, отчёт).
- [ ] Юрист посмотрел формулировки отчёта и согласие родителя (закон РК об ИИ, реклама).
- [ ] В бумажном согласии родителя есть строка о сборе обезличенных данных для исследования.

## Во время пилота

- Менеджер после каждой сессии записывает одну строку: что пошло не так, что ученик или родитель не поняли.
- Раз в неделю копируем папку `%LOCALAPPDATA%\BHS Profor\sessions` с каждого ноутбука и запускаем разбор:

```
python tools/v2/pilot_report.py копия-ноутбук-1 копия-ноутбук-2 > пилот.md
```

## Ворота перехода

| Ворота | Порог |
| --- | --- |
| Медиана длительности сессии | ≤ 13 минут |
| Потерянные визиты (оборвались или не дошли в облако) | 0 |
| Надёжность шкал интересов (альфа) на каждом языке | ≥ 0,7 |
| Доля сессий с годной ЭЭГ (у кого надет ободок) | ≥ 80% |
| Отзывы менеджеров: саммари понятно родителям | большинство «да» |

## Что калибруем по итогам

- Пороги выраженности профиля (сейчас 40 и 20 пунктов), если плоских профилей больше трети.
- Пороги задач на вращение (сейчас 84% и 59%) по реальной точности подростков. Задачи с точностью около 50% или около 100% заменяем.
- Пороги флагов: «слишком быстро» (медиана 1 с) и «однообразно» (10 одинаковых подряд).
- Реакция альфы 1,2 — если показатель внимания скрыт больше чем у половины учеников.

Все пороги собраны в коде в одном месте. Итог любой сессии пересчитывается из её сырых файлов, так что после калибровки старые сессии получат новый итог.
