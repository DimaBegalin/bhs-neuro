# Установка на ноутбук с Windows

Два клика, программистом быть не нужно. Нужны Windows 10 или 11 и
Bluetooth в ноутбуке.

## Шаг 1. Папка

Распакуйте архив «Нейропрофориентация BHS» и положите папку в Документы.

## Шаг 2. Установка

Дважды щёлкните файл `Установить (Windows).bat`. Если Windows покажет синее
окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем
«Выполнить в любом случае»: так она переспрашивает про все скачанные файлы.

Окно само поставит всё нужное и напишет «ГОТОВО». Первый запуск занимает
до минуты. Делается один раз.

Дальше программа запускается сама при каждом входе в Windows.

## Шаг 3. Ободок

1. Включите ободок кнопкой, дождитесь мигания.
2. Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth →
   выберите Headband.
3. **Приложение Mind Tracker на этом ноутбуке должно быть закрыто.**
   На Windows прибор держит только одна программа, и это наша: она сама
   включает поток и сама следит за контактом.

Это главное отличие от MacBook: там Mind Tracker держат открытым, здесь
наоборот.

## Шаг 4. Вход

Откройте сайт в **Chrome** или **Edge** и войдите по почте и паролю.

На странице входа видно состояние: работает ли программа и найден ли ободок.

## Между детьми

После снятия с головы ободок держит связь около тридцати секунд, потом
засыпает. На следующего ребёнка: надеть ободок, нажать на нём кнопку,
дождаться, пока строка «Ободок» в панели станет зелёной. Программа находит
прибор сама, перезапускать ничего не нужно.

## Если что-то не так

- **«Программа не запущена»**: перезагрузите ноутбук. Если не помогло,
  запустите `Установить (Windows).bat` ещё раз.
- **«Ободок не найден»**: нажмите кнопку на ободке (он засыпает), проверьте,
  что Mind Tracker закрыт и что Bluetooth в ноутбуке включён.
- **Хочется увидеть, что пишет программа**: `Запустить (Windows).bat`
  открывает её в окне. Журнал лежит в `logs\bridge.log`.
- **Тест прошёл, а отчёта нет**: откройте панель, карточка появляется
  через полминуты после финального экрана.
- **PDF не скачивается**: нужен Chrome или Edge. Edge в Windows есть всегда,
  так что достаточно, чтобы его не удаляли.

## Снять программу

`Удалить (Windows).bat` убирает автозапуск и останавливает программу.
Записи визитов остаются в папке `data`.

## Для того, кто настраивает

Мост на Windows читает прибор библиотекой производителя (`--channel sdk`,
это значение по умолчанию на Windows). Запасной канал `--channel ble` идёт
через bleak и пока умеет только слушать уже включённый поток: своей команды
включения потока у нас нет. Найти её на живом приборе помогает
`tools/win_find_start_command.py`, найденную команду прописывают строкой
`HEADBAND_START_COMMAND=<hex>` в `.env`.

Что на Windows не работает и не нужно: зеркало окна Mind Tracker и чтение
его базы. Оба слоя контрольные, профиль и отчёт считаются без них.
