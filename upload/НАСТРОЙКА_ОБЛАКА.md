# Настройка облака

Делается один раз. Нужен доступ к проекту Supabase.

## Шаг 1. Таблица и правила доступа

Открыть проект на supabase.com → **SQL Editor** → **New query** → вставить
целиком [schema.sql](schema.sql) → **Run**.

Должно ответить `Success`. Это заводит таблицу визитов и правила, по которым
каждый менеджер видит только свои записи.

## Шаг 2. Ключи

**Project Settings** → **API**. Оттуда нужны два значения:

- **Project URL**
- **anon public** ключ

Вписать их в файл `.env` рядом с программой:

```
SUPABASE_URL=https://ваш-проект.supabase.co
SUPABASE_ANON_KEY=ваш-anon-ключ
```

Ключ `anon` публичный по замыслу: он попадает на страницу сайта, и это
нормально. Записи защищает не он, а правила доступа из шага 1.
Ключ `service_role` не использовать нигде: он обходит все правила.

## Шаг 3. Учётные записи менеджеров

**Authentication** → **Users** → **Add user** → **Create new user**.
Ввести почту и пароль, включить **Auto Confirm User**, иначе менеджер
не войдёт до подтверждения почты.

Повторить для каждого менеджера. Пароль передать лично.

Регистрация со стороны сайта закрыта намеренно: аккаунты заводит школа,
иначе в панель сможет зайти кто угодно.

## Шаг 4. Проверка

Войти на сайте под учётной записью менеджера и провести один тест.
В панели должна появиться карточка. Зайти под вторым менеджером —
первого визита он видеть не должен.
