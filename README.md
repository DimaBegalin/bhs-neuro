# Профориентация BHS с нейромониторингом

Программа для Windows, в которой ученик 8–11 класса за ~13 минут проходит опросник интересов, карточки занятий, задачи на мысленное вращение и опросник стиля работы. Результат: три близких направления с профессиями, саммари из 5 пунктов и PDF для родителя с комментарием профориентолога. ЭЭГ-ободок в это время ведёт нейромониторинг: показывает качество сигнала, внимание к карточкам и состояние. На рекомендацию ободок не влияет (ADR 0001).

Текущая версия — **2.0, ветка `v2`**. Версия 1 (мост к ободку + тест в браузере) лежит в `main` и остаётся в работе у менеджеров до перехода (план — [docs/v2/ПЕРЕХОД.md](docs/v2/ПЕРЕХОД.md)).

## Быстрый запуск на Mac (разработка)

```
.venv/bin/python -m app.main --device sim          # имитатор ободка
.venv/bin/python -m app.main --device sim --fast   # то же, отрезки по 3 с
.venv/bin/python -m app.main                       # проигрыватель записанной сессии
.venv/bin/python -m app.main --device ble          # живой ободок через Mind Tracker
.venv/bin/python -m pytest tests -q                # все тесты (версии 1 и 2)
```

Сборка для Windows: workflow «Windows EXE» на ветке `v2` (`gh workflow run build-windows.yml --ref v2`) выпускает `BHS-Profor-Setup-<версия>.exe`, `BHS-Profor.exe` и утилиту проверки ободка `BHS-SDK-Check.exe`.

## Версия 1 (до перехода)

```
./.venv/bin/python -m bridge.main         # мост к прибору
./.venv/bin/python -m bridge.main --fake  # без прибора
./.venv/bin/python tools/build_site.py    # страницы сайта из web/ в public/
```
