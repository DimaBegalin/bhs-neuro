# Нейропрофориентация BHS: как запустить на визите

Всё крутится локально на MacBook. Интернет нужен только для выгрузки в Supabase,
без него система работает и складывает данные в очередь.

## Холодный подъём после перерыва

1. Ободок включить кнопкой. Новый ноутбук: сопрячь через Mind Tracker.
2. Mind Tracker открыть на вкладке «Мониторинг»: он будит поток прибора.
3. Мост: `./.venv/bin/python -m bridge.main`
4. Страницы: `./.venv/bin/python tools/serve_web.py`
5. Живость: `curl -s http://127.0.0.1:8765/status` – packets должен расти.
6. Облачная панель живёт без ноутбука, ключи облака в `app/.env`.

Полный журнал постройки и все грабли: база bhs-brain, сессия 054.

## Запуск

Первое окно терминала, мост к прибору:

```
cd "~/Beta High School/_funnels/нейротрекер_профориентация/app"
./.venv/bin/python -m bridge.main
```

Второе окно, страницы:

```
./.venv/bin/python tools/serve_web.py
```

Дальше в браузере:

- тест для ребёнка: http://127.0.0.1:8080/index.html
- живой монитор: http://127.0.0.1:8080/monitor.html
- панель диагноста: http://127.0.0.1:8080/panel.html, код доступа 2026

## Порядок на визите

1. Штатное приложение Mind Tracker закрыть. Прибор держит одно подключение,
   и пока приложение с ним связано, наш мост его не увидит.
2. Включить ободок, дождаться зелёного индикатора.
3. Открыть тест, ввести идентификатор сессии (латиница, цифры, дефис).
4. Надеть ободок ребёнку, дождаться зелёного контакта по четырём точкам.
5. Отдать ноутбук ребёнку. Дальше он идёт сам: калибровка полторы минуты,
   четыре блока задач, около восьми минут вместе с надеванием.
6. Профиль считается автоматически при завершении. Открыть панель и вести разбор.

## Если что-то пошло не так

Мост не поднялся или прибор отвалился: тест всё равно работает до конца,
сессия помечается как сессия без нейро-слоя, разбор идёт по точности и времени.

Сигнал был грязный: профиль придёт без цены усилия, в панели будет написана
причина. Это защита, а не поломка, документ с мусором внутри опаснее.

## Работа без прибора

```
./.venv/bin/python -m bridge.main --fake
```

Генератор выдаёт сигнал с дышащей альфой: можно репетировать сценарий визита
и отлаживать экраны.
